⚙️ freguesbot

Bots clássicos em Python que trabalham para pequenos negócios. Sem IA generativa, sem mensalidade, código aberto.

Por que sem LLM? Um bot de regras e estatística não inventa preço nem promessa: só responde o que o dono cadastrou. Roda no seu computador, não manda seus dados para ninguém e custa zero.

O que já existe

🔎 Gerador de leads. Escolhe nicho e cidade, busca estabelecimentos no OpenStreetMap, dá nota por regras que ele explica (tem telefone? não tem site?) e sugere a abordagem. Não dispara mensagem nenhuma.
💬 Atendimento. Entende gírias e erros de digitação ("qto é o corte?"), conduz o agendamento perguntando só o que falta e passa para uma pessoa quando não sabe. Reclamação vai sempre para um humano.
📈 Pesquisa viral. Calcula engajamento ÷ seguidores e separa o top 5% do conteúdo.

Quão bom é, de verdade

O atendimento acertou 75% em frases novas de teste e encaminha ao humano o que não entende. Ele melhora conforme o dono cadastra as perguntas reais do negócio. Os números e as limitações estão no README, sem maquiagem.

Como usar

git clone <repositório>
cd freguesbot
python3 -m bots.leads.run --niche barbearia --city "Goiânia" --state "Goiás" --csv leads.csv
